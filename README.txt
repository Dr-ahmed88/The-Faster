The Faster — ملف المشروع
========================
المحتوى: index.html (النسخة المحدّثة: الترشيح الاسترشادي + المخطط السنوي + التصميم الجديد)

مهم: ملفات الصور والأيقونات الأصلية موجودة في مستودعك ولم تصلني، لذلك لم أضعها هنا.
اسم المنصة كما هو: The Faster.

الخطوات:
1) في مجلد المشروع الأصلي (فيه hero.jpg و icon-192.png و manifest.webmanifest) ضع index.html هنا بجانبها.
2) يجب أن يكون اسم الملف index.html بالضبط (احذف (1) من الاسم).
3) ارفع الملف إلى https://github.com/Dr-ahmed88/The-Faster (Add file > Upload files > Commit changes).
4) افتح https://dr-ahmed88.github.io/The-Faster/ ثم Ctrl+Shift+R.

إذا فتحت index.html وحده من سطح المكتب فلن تظهر الصورة لأن hero.jpg ليس بجانبه؛ ستظهر خلفية خضراء بدلها مع اسم The Faster، وعلى GitHub تظهر الصورة طبيعيًا.
